# tree-sitter-vb6 Design Spec

**Date:** 2026-06-04
**Status:** Approved

## Overview

Build `tree-sitter-vb6`: a tree-sitter parser for Visual Basic 6.0 targeting static analysis and migration tooling use cases.

**Sources:**
- Scaffold: `../tree-sitter-vb-dotnet/` (project files, helpers)
- Grammar reference: `../proleap-vb6-parser/src/main/antlr4/io/proleap/vb6/VisualBasic6.g4`
- Test inputs: `../proleap-vb6-parser/src/test/resources/` (`.cls` files)

## Decisions

| Decision | Choice | Reason |
|---|---|---|
| Use case | Static analysis + migration tooling | Needs precise structure and full VB6 fidelity |
| File scope | `.cls` and `.bas` only | Skip `.frm` form designer `BEGIN...END` blocks |
| Node naming | `snake_case` (tree-sitter convention) | Ecosystem compatibility; renaming later is mechanical |
| Approach | Hybrid: vb-dotnet scaffold + helpers, grammar written fresh | Avoids VB.NET assumption leaks and ANTLR4 impedance mismatch |
| Tests | Convert proleap `.cls` files to tree-sitter corpus format | Maximum coverage from proven VB6 examples |

## Grammar Architecture

### Top-level

```
source_file
  module_header?           # VERSION 1.0 CLASS  (.cls only)
  attribute_statement*     # Attribute VB_Name = "ClassName"
  module_options?          # Option Explicit / Option Base / Option Compare
  module_body
```

### Module body declarations

```
module_body →
  sub_declaration
  function_declaration
  property_get_declaration
  property_set_declaration
  property_let_declaration
  declare_declaration        # Declare Function/Sub (DLL binding)
  type_declaration           # Type Foo ... End Type
  enum_declaration           # Enum Foo ... End Enum
  event_declaration          # Event Foo(args)
  const_declaration          # module-level Const
  deftype_declaration        # DefInt A-Z
  implements_declaration     # Implements IFoo
```

### Block statements (inside Sub/Function/Property bodies)

~40 statement types including:

```
assignment_statement     # x = expr  (implicit Let)
let_statement            # Let x = expr  (explicit)
set_statement            # Set obj = New Foo
call_statement           # Call foo(args) or bare foo args
dim_statement            # Dim x As Type
redim_statement          # ReDim [Preserve] x(n)
const_statement          # Const x = 1
if_statement             # If / ElseIf / Else / End If
select_case_statement    # Select Case / Case / End Select
for_next_statement       # For i = 1 To n [Step s]
for_each_statement       # For Each x In collection
while_statement          # While cond / Wend
do_loop_statement        # Do [While/Until] / Loop [While/Until]
with_statement           # With obj / End With
goto_statement           # GoTo label
gosub_statement          # GoSub label
return_statement         # Return  (GoSub return, not function return)
on_error_statement       # On Error GoTo label / Resume Next / GoTo 0
on_goto_statement        # On expr GoTo l1, l2
on_gosub_statement       # On expr GoSub l1, l2
resume_statement         # Resume / Resume Next / Resume label
exit_statement           # Exit Sub/Function/For/Do/Property
label_statement          # labelName:
raise_event_statement    # RaiseEvent Foo(args)
mid_statement            # Mid(s, i, n) = expr
... + ~20 I/O and file statements (Open, Close, Print, Write, Input, etc.)
```

### Expressions

```
expression →
  literal
  identifier
  member_access_expression   # obj.prop
  index_expression           # arr(i)
  call_expression            # foo(args)
  new_expression             # New Foo
  typeof_is_expression       # TypeOf obj Is Type
  unary_expression           # Not x, -x, +x
  binary_expression          # full VB6 operator precedence
  parenthesized_expression   # (expr)
```

Binary operator precedence (high to low): `^` → `* / \ Mod` → `+ -` → `&` → `= <> < > <= >= Is Like` → `And` → `Or Xor` → `Eqv Imp`

Unary operators (`Not`, `-`, `+`) handled separately in `unary_expression`.

### Helpers (from vb-dotnet)

- `kw(word)` — case-insensitive keyword token with precedence
- `ci(keyword)` — builds case-insensitive regex
- `commaSep(rule)` / `commaSep1(rule)`
- `_terminator` — newline or `:`
- `_line_continuation` — `_` + newline (treated as extra/whitespace)

## Key VB6-Specific Constructs

| tree-sitter node | VB6 syntax | Migration relevance |
|---|---|---|
| `module_header` | `VERSION 1.0 CLASS` | Identifies file type |
| `attribute_statement` | `Attribute VB_Name = "..."` | Module metadata |
| `deftype_declaration` | `DefInt A-Z` | Implicit type defaults |
| `type_declaration` | `Type Foo ... End Type` | UDT (struct equivalent) |
| `let_statement` | `Let x = expr` | Explicit assignment |
| `goto_statement` | `GoTo label` | Control flow migration |
| `gosub_statement` | `GoSub label` | Subroutine calls |
| `return_statement` | `Return` | GoSub return (not function return) |
| `on_error_statement` | `On Error GoTo / Resume Next` | Error handling migration |
| `resume_statement` | `Resume [Next\|label]` | Error recovery |
| `on_goto_statement` | `On expr GoTo l1, l2` | Computed jumps |
| `label_statement` | `labelName:` | Jump targets |
| `mid_statement` | `Mid(s, i, n) = expr` | Special string assignment |
| `implements_declaration` | `Implements IFoo` | Interface implementation |
| `declare_declaration` | `Declare Function Lib "..."` | DLL bindings |

### ambiguousIdentifier handling

VB6 allows many keywords as identifiers (`Text`, `Name`, `Date`, `Time`, `Left`, `Right`, etc.). Proleap uses a blanket `ambiguousIdentifier` rule. Tree-sitter handles this via:
- `alias(kw('Date'), $.identifier)` patterns at call sites
- `conflicts` entries for ambiguous parse states
- Keeping `identifier` permissive in argument/property positions

## Test Strategy

### Corpus structure

| file | proleap source | what it covers |
|---|---|---|
| `test/corpus/module.txt` | `io/proleap/vb6/ast/` | module header, attributes, options |
| `test/corpus/statements.txt` | `com/microsoft/msdn/statements/` | all ~40 block statements |
| `test/corpus/expressions.txt` | hand-written | literals, operators, call forms |
| `test/corpus/declarations.txt` | `com/microsoft/msdn/statements/` | Sub, Function, Property, Type, Enum |

### Corpus format

```
================================================================================
Test name
================================================================================

<vb6 source from proleap .cls file>

--------------------------------------------------------------------------------

(source_file
  (module_body
    (sub_declaration
      name: (identifier)
      body: (block
        (beep_statement)))))
```

### Development workflow per statement

1. Write grammar rule
2. `tree-sitter generate && tree-sitter test` (expect fail — no test yet)
3. Add corpus case from proleap `.cls`, fill expected S-expression output
4. Green → next statement

Proleap `.tree` files used as **semantic reference only** — not copied verbatim (different format).
